# cafework

## Stack

- Vite (SPA)
- TypeScript strict
- TanStack Router (file-based routes in `src/pages`)
- TanStack Query v5
- Zustand
- Tailwind CSS v4 + shadcn/ui + Sass
- React Hook Form + Zod
- ESLint + Prettier

## Scripts

```bash
npm run dev           # start dev server
npm run build          # typecheck + production build
npm run preview        # preview production build
npm run lint            # eslint
npm run format          # prettier --write
npm run format:check    # prettier --check
```

## Adding shadcn/ui components

```bash
npx shadcn@latest add <component>
```

## Structure

```
src/
  assets/
    images/, fonts/   static assets
    styles/
      tailwind.css    Tailwind entry + shadcn theme tokens (keep as .css, see note below)
      basic.scss      custom Sass styles
  components/
    layout/           layout components (e.g. root-layout)
    ui/               shadcn/ui components
  lib/                query-client, utils
  pages/              TanStack Router file-based routes
  store/              zustand stores
  router.tsx          router instance
  routeTree.gen.ts    auto-generated by @tanstack/router-plugin, do not edit
```

> `tailwind.css` must stay a `.css` file — `@tailwindcss/vite` only intercepts `.css` files to resolve `@import "tailwindcss"`, `@theme`, and `@apply`. Renaming it to `.scss` will break Tailwind (Sass will try to resolve the import itself and fail, or leave `@apply` unprocessed). Put custom styling in `basic.scss` instead.
